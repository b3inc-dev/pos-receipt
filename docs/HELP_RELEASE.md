# POS Receipt 利用者ヘルプ

関連要件 #17。サイト側の対応パスは /help/pos-receipt/ 。

## 導入・通常操作・例外
- 初期設定では利用条件、必要な権限、動作確認方法を記録する。
- 通常操作の対象は「商業施設の決済内訳と、閉店時の精算を照合する。」。導入者視点の手順と期待される結果を合成データで確認する。
- 症状別の初稿「返品した注文が精算に反映されない」
  1. 注文の返品・返金の状態をそれぞれ確認します。返品の登録だけで返金まで完了したとは判断できません。
  2. 対象の日付・集計店舗・返金に使った決済手段を確認し、該当する精算の返金欄と比較します。
  3. 差額が残る場合は金額と支払種別を控えます。精算表示を合わせる目的で再返金する前に元取引を確認してください。

## 変更時の確認
画面や手順の変更時は、アプリの変更PRから該当するサイト記事の差分を参照する。対象版、実際の画面名、操作結果、再試行可否を確認した上で案内する。上記は初稿であり実機確認済みの手順ではない。
