# 印字操作メモ（精算・点検・領収書・販売レシート）

アプリ独自のレシートは **Shopify Printing API** だけを使います。CloudPRNT の URL 設定や、精算用の Shopify 注文から印字する操作は使わないでください。

## 準備

1. Shopify POS **11.11 以降**
2. レシートプリンタを POS にペアリングし、接続中にする
3. 用紙幅（58mm / 80mm）は、精算・点検・領収書なら管理画面「印字設定」、販売・ギフトなら「販売レイアウト編集」で選ぶ
4. アプリの Lite / Pro は Shopify POS の Lite / Pro とは別です。販売レシートはアプリ Lite 以上

## 精算・点検

1. POS の精算タイルで対象日を確認して発行する
2. 完了画面の「プリンタへ送信」を押す（接続中のプリンタのみ）
3. 「プリンタへ送信しました」は **送信受付** です。紙が出たことの保証ではありません
4. プリンタが未接続のときは成功になりません。「システム印刷ダイアログを開く」は直接印字とは別です
5. 応答が遅いときは成否不明と表示します。自動では再送しません。紙が出ていなければ履歴から再印刷してください
6. 再印刷は発行時の店舗表示名・金額・帳票版を使います。あとから店名を変えても、その履歴の紙面の店名は変わりません。売上や精算データは増えません
7. 用紙幅はいまのプリンタ設定です。帳票の金額や店名とは別に扱います
8. 連打しても二重送信しません

## 領収書・販売レシート

同じ Printing API です。領収書の「同じ取引を再発行する」は新しい発行記録を作ります。履歴の「保存済みを再印刷」は記録を増やさず印字だけします。

## ギフトレシート

POSの販売レシートで取引を選び、「金額なしのギフトレシートに切り替え」→「ギフトレシートをプリンタへ送信」を押します。注文番号、品名、数量を印字します。金額・税・割引・支払内訳・自由入力の注文属性や商品属性はギフト用のデータに含めません。品名自体は注文に記録された表記を使います。

管理画面「販売レイアウト編集」の「ギフトレシートをプレビュー（金額なし）」で、選んだ紙幅の見本を確認できます。実機での出力結果は、利用するプリンタと用紙で確認してください。

## しないこと

- 管理画面の古い印字方式（注文経由 / CloudPRNT）を復活させる
- 精算のために SETTLEMENT / INSPECTION 注文を探す
- タイムアウト後に同じ操作を自動リトライする（手動の再印刷は可）
