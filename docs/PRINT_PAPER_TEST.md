# 印字の一本化（#22）を紙で確かめる手順（mPOP・mC-Print3）

対象: #22（アプリ独自の印字を `shopify.printing` だけにする）。精算・点検・領収書・販売レシート・ギフトレシート。

- この手順は下書きです。本番の店では試しません。**開発ストア `bbbincbbb` だけ** で試します
- T がやるところは **【T】**、エージェントがやるところは **【係】** と書きます
- 紙は 1 枚ずつ写真を撮って、#22 にコメントで貼ります（店名・金額が見えれば十分）
- 結果は最後の表に ○ / × を書きます。× が 1 つでもあれば #22 は main へ入れません

---

## 0. 先に知っておくこと

- 「プリンタへ送信しました」は **送信を受け付けた** という意味です。紙が出たかは目で見ます
- 送ってから 20 秒返事がないと「成否不明」と出ます。自動では送り直しません。紙が出ていなければ、履歴から手で再印刷します
- 用紙幅は帳票の中身ではなく、プリンタの設定です。幅を変えても金額・店名は変わりません
- 精算注文（SETTLEMENT / INSPECTION）は **作られなくなります**。開発ストアの注文一覧に精算注文が増えないことも見ます

### 機種と紙

| 機種 | 紙の幅 | 試す幅 |
|---|---|---|
| Star mPOP（POP10） | 58mm | 58mm |
| Star mC-Print3 | 80mm（58mm も入る） | 80mm、紙を入れ替えられれば 58mm も |

- [ ] #22 の最新の head（SHA）を T に伝える。#53（main の取り込み）を入れたあとの head にする
- [ ] 開発ストアで動かすアプリが公開用（POS Receipt）か自社用（POS Receipt - Ciara）かを T と確かめる

## 2. 【T】パソコンで開発ストア用に起動する

`pos-receipt` のフォルダで打ちます（`<SHA>` は【係】が伝えた番号）。

```bash
git fetch origin
git switch --detach <SHA>
npm ci
npm run dev:public
```

- 途中で「URL を書き換えますか」と聞かれたら、上の注意のとおりに答えます
- 終わったら `Ctrl+C` で止めて、`git checkout -- .` と `git switch main` で元に戻します（コミットしない）

## 3. 【T】iPad の準備

- [ ] Shopify POS が **11.11 以降**（設定 → 情報）
- [ ] プリンタを POS の設定 → ハードウェアでペアリングして「接続中」
- [ ] POS を一度とじて開き直し、POS Receipt のタイルが出る
- [ ] 管理画面「印字設定」の「レシート用紙幅」を、つないだプリンタの紙に合わせて保存（精算・点検・領収書）
- [ ] 管理画面「販売レイアウト編集」の用紙幅も同じに合わせて保存（販売・ギフト）

## 4. 【T】紙で確かめる（機種ごとに 1 回ずつ）

### A. 精算
1. [ ] 精算タイル → 今日の日付で精算を発行
2. [ ] 「プリンタへ送信」→ 紙が 1 枚出る。店名・日付・金額・支払の内訳が切れずに読める
3. [ ] 金額が精算プレビューの画面と同じ
4. [ ] 開発ストアの注文一覧に精算注文（SETTLEMENT）が増えていない

### B. 点検
1. [ ] 精算タイル → 点検を発行 →「プリンタへ送信」→ 表題が「点検」で紙が出る

### C. 精算の再印刷
1. [ ] 管理画面「設定」→「ロケーション設定」の「表示名」を一時的に変えて保存
2. [ ] POS の精算タイルの「履歴一覧」から A の精算を開いて再印刷 → **前の店名のまま**、金額も A と同じ
3. [ ] 精算履歴の件数が増えていない
4. [ ] 表示名を元に戻して保存

### D. 領収書
1. [ ] 領収書タイル → 注文を選んで発行 →「プリンタへ送信」→ 宛名・金額・但し書きが読める
2. [ ] 「同じ取引を再発行する」→【再発行】と入った紙が出る
3. [ ] 履歴の「保存済みを再印刷」→ 前と同じ紙が出る（発行の記録は増えない）

### E. 販売レシート
1. [ ] 販売レシートで取引を選ぶ →「販売レシートをプリンタへ送信」
2. [ ] 長い商品名が折り返して読める。数量・単価・金額の **右端の桁が切れていない**（58mm で特に見る）

### F. ギフトレシート
1. [ ] 同じ取引で「金額なしのギフトレシートに切り替え」→「ギフトレシートをプリンタへ送信」
2. [ ] 品名・数量・注文番号は出て、**金額・税・割引・支払は出ない**
3. [ ] 管理画面「販売レイアウト編集」でギフトの見出しを変えて「ギフト設定を保存」→ 保存のトーストが出る → もう一度送ると新しい見出しになる

### G. うまくいかないとき（紙が出ないのが正しい）
1. [ ] プリンタの電源を切る →「プリンタへ送信」→ 「接続中のプリンタがありません」と出て、成功にならない
2. [ ] 電源を入れ直して接続中に戻ったら、もう一度送ると 1 枚だけ出る
3. [ ] 「プリンタへ送信」をすばやく 2 回押す → 紙は 1 枚だけ
4. [ ] 「システム印刷ダイアログを開く」は、押したときだけ画面が出る（勝手に出ない）

### H. 用紙幅の切り替え（mC-Print3 で 58mm の紙があるときだけ）
1. [ ] 用紙幅を 58mm にして保存 → E と同じ取引を送る → 右端が切れない
2. [ ] 80mm に戻して保存 → 同じ取引を送る → 80mm の幅いっぱいに出る
