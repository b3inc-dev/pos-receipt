## 4. 数字の並行運用（段 B）

### 4-1. 期間と範囲

- **7 日以上つづけて**。土日を 1 回以上、返金・特殊返金・商品券のある日を 1 日以上ふくむ。月末をまたげるならまたぐ
- 全店（実店舗 10 店）。EC は §2-4 で決めた扱い
- このあいだ精算の正は今のまま。店の操作は変えない

### 4-2. 毎日やること

| 時 | だれ | 何を |
|---|---|---|
| 閉店のあと | 店 | 今のやり方で精算する（今までどおり） |
| 閉店のあと | 店 | POS Receipt の精算タイルで精算を確定する（保存が要る。#68 の CSV は保存した精算だけを出す） |
| 次の朝 | 【係】 | 前の日の CSV を出す: `GET /api/settlements/export-csv?dateFrom=YYYY-MM-DD&dateTo=YYYY-MM-DD`（管理画面に入ったまま開く。#22 までボタンは無い） |
| 次の朝 | 【係】 | ciara-system の同じ日・同じ店の数字を出す（ciara-system は夜の Job で前の日のキャッシュを作る） |
| 次の朝 | 【係】 | §4-3 の表で照らし、差の表（§4-5）を書いて T さんに渡す |
| 差が出た日 | 【係】 | その日・その店だけ GAS の精算レシートでも数字を出す |

店が精算を確定し忘れた日は、POS の精算タイルで日付を選んで確定するか、`/api/debug/settlement-compare?locationId=…&locationName=…&targetDate=…`（自社用だけ・保存しない）で同じ数字を見る。

### 4-3. 照らす項目

CSV（#68）の 1 店 × 1 日 = 「精算合計」の行 1 つ ＋「支払方法」の行が支払方法の数だけ。

| 区分 | CSV の列 | settlement-compare | ciara-system / GAS |
|---|---|---|---|
| 精算合計 | 売上 | `summary.total` | `_total` |
| 精算合計 | 税抜売上 | `summary.netSales` | `_actual` |
| 精算合計 | 消費税 | `summary.tax` | `_tax` |
| 精算合計 | 割引 | `summary.discounts` | `_discount` |
| 精算合計 | ポイント利用 | `summary.vipPointsUsed` | `_vip` |
| 精算合計 | 返金 | `summary.refundTotal` | returns |
| 精算合計 | 取引件数 | `summary.orderCount` | `_order_count` |
| 精算合計 | 返金件数 | `summary.refundCount` | `refund_order_count` |
| 精算合計 | 商品券釣銭 | （プレビューの商品券釣り） | 商品券釣り |
| 支払方法 | 売上・返金・差引・取引件数・返金件数 | `payments[表示名]` | 支払方法ごとの行 |

販売点数は CSV に列が無い。settlement-compare か精算レシートで見る。

### 4-4. 合格のしきい値

- **金額はすべて 0 円差**（店 × 日 × 支払方法、と精算合計の各項目）
- **件数はすべて 0 件差**
- 差が出た日は §4-5 で理由を書く。理由が「数え方の設定」「マスタの抜け」だったときは、直したあと **並行運用の 1 日目から全部の日を作り直して**（精算タイルの再計算）0 差になれば、その日も合格に数える
- 「比べる相手の誤り」と分かった差は、T さんが認めたら合格に数える（差の表に残す）
- 合格の条件: **7 日つづけて全店が 0 差（または T さんが認めた差だけ）**。この結果を T さんが見て、段 D に進むかを決める

### 4-5. 差が出たとき

1. **時刻のずれでないか**: 精算のあとに注文が直った・返金された。両方を作り直してもう一度比べる
2. **どの注文か**: `settlement-compare` の返事（`debug: true`）の注文の一覧と、ciara-system のその日の注文を突き合わせて、差の出た注文を見つける
3. **どこの差か** を下から選ぶ

| 種類 | 例 | 直し方 |
|---|---|---|
| 設定 | 売上の日・ノベルティ・wespo・ギフトカードの返金・件数・マイナス | §2-2 を直して作り直す |
| マスタ | 「未分類」に載った・施設のポイントが 1 行目に載った | §2-3 に足して作り直す |
| 返金の計上先 | 他の店で返金した分が違う店に載った | §2-1 と §7-1 を見る |
| アプリの誤り | 上のどれでもない | Issue を立て、別の PR で直す（この手順書ではアプリを変えない） |
| 比べる相手の誤り | ciara-system と GAS の数字が食い違い、アプリが GAS と同じ | 差の表に書いて T さんに判断をもらう |

4. 差の表（日・店・支払方法・項目・アプリ・相手・差・注文・種類・直したか）を書き、連絡帳 #39 に 1 行で残す
