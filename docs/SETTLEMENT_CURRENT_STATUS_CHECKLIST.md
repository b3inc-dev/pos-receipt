# 精算処理の現状チェックシート

最終更新日: 2026-08-18  
対象: POS Receipt の「精算」機能

印字経路の改訂（Shopify Printing API 1本化）は `docs/SETTLEMENT_PRINT_UNIFICATION.md`。本チェックシートの D-3 / D-4 は現行互換経路用。標準経路（`shopify_printing`）実装後は D-3b を追加する。

---

## 0. 使い方

- 各項目を実施して、`OK / NG / 未実施` のどれかを記入してください。
- `NG` の場合は、再現手順と画面メッセージをメモ欄に残してください。
- まずは **A → B → C** の順で進めると確認しやすいです。

記入例:

| 判定 | メモ |
|---|---|
| OK | 期待どおり動作 |
| NG | 〇〇ボタン押下後に 500 エラー |
| 未実施 | テストデータ不足 |
