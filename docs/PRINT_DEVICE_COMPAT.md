# レシートプリンタ対応表（shopify.printing）

本環境では **紙への実印字は未実施**。mPOP 対応はユーザー報告として記録する。

## 用紙幅

| 幅 | HTML | 備考 |
|----|------|------|
| 80mm | 既定。`PrintSettings.cloudprntPaperWidth`（互換キー） | CSS 最大幅 576px 相当 |
| 58mm | 管理画面のレシート用紙幅で選択 | CSS 最大幅 384px 相当 |

CloudPRNT プロトコル自体は使わない。キー名だけ互換読み取りする。

## 機種

| 機種 | 接続 | 直接印字（HTML） | 本環境での紙面確認 | 根拠 |
|------|------|------------------|---------------------|------|
| Star mC-Print3 | POS ペアリング + `connected: true` | 対応想定 | **未確認** | Shopify Printing API のハードウェアレシートプリンタ |
| Star mPOP（POP10） | 同上 | ユーザー報告では直接印字可能 | **未確認**（この VM / サンドボックスでは紙を出していない） | ユーザー明示報告。初期要件で未対応だったため order_based を置いていた |
| その他 POS ペアリング済みレシートプリンタ | `connected: true` のみ | HTML / 画像。PDF + printer 指定は不可 | **未確認** | Shopify ドキュメント |
| 未接続 / オフライン | 直接印字しない | ダイアログは明示操作時のみ | — | 未接続を成功扱いしない |

## POS バージョン

- `shopify.printing.getPrinters` / 直印字: **POS 11.11.0+**
- 拡張 `api_version`: **2026-07**
- 古い POS は `getPrinters()` が空配列になり得る → 未接続と同じ（成功にしない）

## 帳票内容（維持）

店舗情報、金額、税、会員割引、配送、担当表示など、既存の販売／精算／領収書レンダラが持つ項目は維持する。本 PR は印字経路の一本化であり、帳票項目の削除ではない。
